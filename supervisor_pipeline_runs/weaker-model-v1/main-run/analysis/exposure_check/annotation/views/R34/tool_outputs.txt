    36	 *          offset fields in the Local or Central directory

    38	 *          a Zip64 extended information record is created.
    39	 *          The order of the fields in the zip64 extended

    44	 *          Note: all fields stored in Intel low-byte/high-byte order.

    46	 *          Value      Size       Description
    47	 *          -----      ----       -----------
