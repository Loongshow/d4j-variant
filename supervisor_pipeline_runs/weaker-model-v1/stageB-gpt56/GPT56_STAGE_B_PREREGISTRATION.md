Written 2026-10-15, before any GPT-5.6 call on a Stage B instance. The block plans embed this file's sha256 in their purpose
field; any later change to this file is recorded as an amendment in `../AMENDMENTS.md`, never made silently.

## Question

Does the Stage B accuracy drop observed on gpt-5.5 transfer to GPT-5.6 when nothing but the model changes?

gpt-5.5 reference (verified records: `../STAGE_B_RESULTS.md`, `../analysis/stageB_cells.json`, 60 runs, 2026-10-14):
C00 15/15, C01 14/15, C10 3/15, C11 4/15; 1-hop pooled 29/30 against 5-hop + lie pooled 7/30 (difference -0.73, Fisher
two-sided p = 3.4e-9); odd hop 18/30 against 18/30. The 24 misses were blind-labelled ENTRY_POINT_BIAS 17, CONVENTION_PRIOR 6,
ATTRIBUTION_FAILURE 1.

## Execution

60 valid behavioural runs: block 1 (40 slots, B1 and B3) then block 2 (20 slots, B4), back to back on w56 through
`scripts/wm_run_chain.sh` under `caffeinate`. The block is completed whatever the early outcomes are. The frozen driver's uniform
rules apply unchanged: three passing health probes before each launch; a run classified `provider_stall` (rules 1 and 2) or
another infrastructure status is excluded and its slot gets one replacement; a slot that fails twice as infrastructure, six
failed probes in a row, a credit or quota error, contamination, an integrity or protocol-identity break halts the block for
review. Valid runs are never replaced.

## Outcomes

Primary outcome: Acc@1 (gold ranked first). Primary contrasts, Fisher exact two-sided with Wilson 95% intervals:

- P1: C00 against C10 (n = 15 each)
- P2: C01 against C11 (n = 15 each)
- P3: 1-hop pooled (C00 + C01, n = 30) against 5-hop + lie pooled (C10 + C11, n = 30)

Secondary: C00 against C01; C10 against C11; MRR; gold rank; gold exposed but misranked; blind failure-mode label; tool calls;
first gold exposure (step and seconds, computed by the same timeline tool for both models); wall time. Model comparison is
descriptive: per cell and per project gpt-5.5 against GPT-5.6, Fisher per cell, the model x cell pattern as differences of
differences. Two models do not support a causal capability claim and none will be made.

### Classification fixed now (on P3)

| Class | Rule |
|---|---|
| REPLICATED (the collapse transfers) | 5-hop + lie pooled <= 12/30 (<= 0.40) and the P3 difference >= 0.40 with p < 0.05 |
| ATTENUATED (partial recovery) | 5-hop + lie pooled between 13/30 and 26/30, or a significant P3 difference below 0.40 |
| ELIMINATED (back at ceiling) | 5-hop + lie pooled >= 27/30 (>= 0.90) and the P3 difference not significant (p >= 0.05) |
| BASELINE_SHIFT (flag, reported alongside) | 1-hop pooled < 24/30; the class is then read from the P3 difference alone |

### Decision rule fixed now (from the brief)

REPLICATED: the decomposition block (hop distance, cross-file dispersal, facade lie) is recommended as the next experiment.
ATTENUATED: the decomposition is still recommended, as the place to locate the capability gap. ELIMINATED: no decomposition
without the supervisor's approval; the report states the gpt-5 / gpt-5.5 / GPT-5.6 pattern only as far as the GPT-5 timeout
analysis supports it. In every case the decomposition is proposed, not launched.

## Expectation stated before any run

The records point both ways. GPT-5.6 ranked the gold first in 43 of 44 runs on the September 5-hop chain arms without an odd hop
and on the held-out set, which predicts recovery. But gpt-5.5 was also at ceiling on the same held-out set (27/27) and still
fell to 7/30 here. My expectation is ATTENUATED or ELIMINATED. A REPLICATED result would be a surprise relative to the September
record. If GPT-5.6 misses, I expect the same shape as gpt-5.5: gold found, fault line on screen, facade ranked first.

## Failure-mode labelling

Every GPT-5.6 miss: two blind labellers (process lens, argument lens) with `construction/stageB/LABEL_BRIEF.md` unchanged; neither
is told the model or the cell; disagreements on primary, secondary or defensibility go to a third adjudicator with the same
instructions used for the gpt-5.5 blocks (including the B4 rule that the primary follows the agent's own stated reason for
rank 1). Cross-model questions answered from the labels: is ENTRY_POINT_BIAS still present; is the gold still named and the
divergence still located at it; is extra evidence retrieved; is the lie cited; is fault location kept apart from the behavioural
entry point.

## Known measurement caveat

The frozen `gold_exposed` / `full_gold_read` miss fault lines shown through `nl -ba | grep -n` (W16). As for gpt-5.5, any GPT-5.6
miss coded `gold_exposed = false` gets an extended-view check, and both readings are reported; the frozen values are not changed.

## Cost

Estimate before launch: about $11 to $13 for the 60 runs (GPT-5.6 averaged $0.19 per run in mechanism-search-v1; on the nine

re-acceptance smoke (about $0.31) and health probes (about $0.01 each). Ceiling set by the user: about $30. If the running cost
reaches $25 before the block ends, the block pauses and the user is asked.
